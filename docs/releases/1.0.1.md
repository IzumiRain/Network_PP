# Network++ 1.0.1

**Date:** 2026-11-07 · **Tag:** `v1.0.1`

Security and compliance release.

## Security

- **XSS hardening (P1):** all untrusted data — content-pack metadata, DNS
  answers, HTTP headers, scan banners, ARP rows, PCAP summaries, registry
  entries — is now HTML-escaped before rendering. The webview holds Tauri
  invoke, so a stored XSS from a malicious pack or hostile network response
  previously meant full backend access. Found via a focused trust-boundary
  review (security-audit-skill methodology).
- Ping target sanitization: flag-like arguments rejected before invoking the
  system ping.
- Content-pack parser tolerates CRLF frontmatter (git `autocrlf` checkouts
  broke TOML parsing on CI) + `.gitattributes` enforcing LF + regression
  test. **94/94 tests.**
